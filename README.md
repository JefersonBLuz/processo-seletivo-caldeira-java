## Sobre o projeto

O objetivo deste projeto é demonstrar conhecimentos em lógica de programação, estruturação de código em Java e uso do Git para versionamento. Todas as atividades estão centralizadas no arquivo `Main.java`, localizado na pasta `src/`.

- **Autor:** Jeferson Braga  
- **Data de criação:** 22/06/2025

## Sobre o Instituto Caldeira

O [Instituto Caldeira](https://institutocaldeira.org.br) é um hub de inovação localizado em Porto Alegre/RS, dedicado a conectar empresas, startups, universidades e talentos para impulsionar a transformação digital e o empreendedorismo no Brasil.

## Atividades Realizadas

- Desenvolvimento de lógica de programação em Java
- Manipulação de variáveis, estruturas condicionais e de repetição
- Organização do código no arquivo [`Main.java`](https://github.com/JefersonBLuz/processo-seletivo-caldeira-java/blob/main/src/Main.java)
- Uso do Git e GitHub para versionamento e colaboração

## Como executar

1. Certifique-se de ter o [Java JDK](https://www.oracle.com/br/java/technologies/downloads/) instalado na sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com/JefersonBLuz/processo-seletivo-caldeira-java.git
   ```
3. Acesse o diretório do projeto:
   ```bash
   cd processo-seletivo-caldeira-java/src
   ```
4. Compile e execute o arquivo `Main.java`:
   ```bash
   javac Main.java
   java Main
   ```
